# 工单分类标签

在实施工单的 `Status:` 行填写对应标签，例如 `Status: needs-info`。

| 技能角色 | 本地标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告人补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已明确，代理可独立实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 已决定不处理 |
