# OpenWrt LuCI 插件首版规格

用户可以在 OpenWrt 管理页面下载精简版 Tailscale、配置参数、启动服务和查看日志。

## 安装与已有节点

| 首次打开插件时的设备情况 | 验收场景 |
| --- | --- |
| 全新路由器 | 官方 OpenWrt 24.10 用户安装 `.ipk`，25.12 用户安装 `.apk`。装好插件后，可直接在浏览器下载适合路由器架构的精简版 Tailscale、配置并启动服务。 |
| 已通过本项目脚本安装 | 页面识别现有服务。已登录的路由器沿用原有节点身份。网页与 `tailscale-helper` 共同管理同一节点，在任一入口保存的设置都能从另一入口读到。例如，通过终端更改下载镜像后，刷新网页即可看到新地址。 |
| 已通过 OpenWrt 软件源安装 Tailscale | 页面显示安装来源和处理指引。打开页面和安装插件均应保留现有服务、程序和节点身份，由用户决定如何处理。 |

## 下载与版本

- 首次下载默认选择最新版本和本地安装。用户也可以选择内存安装，或在高级设置中指定版本和下载镜像。
- 用户指定版本后即锁定到该版本。开机检查、定时更新和通过命令行菜单触发的更新均须遵守锁定选择。内存安装重启时重新下载同一版本，即使上游已经发布新版。
- 用户主动切回“跟随最新”后，更新才按最新发布版本执行。页面分别显示当前安装版本与版本策略。

### 已启用自动更新的旧节点

接入旧节点时，插件读取实际安装的版本，并沿用该节点原有的更新行为。例如，用户最初通过脚本安装 A 版并启用自动更新，随后节点自动升级到 B 版。首次打开 LuCI 时，页面应显示当前版本为 B、版本策略为“跟随最新”。用户此后在网页或命令行菜单中主动指定版本，才进入锁定状态。

## 配置、启动与日志

- 首屏提供主机名、DNS、子网路由、出口节点和自定义控制服务器等常用设置。脚本支持的其余参数按用途放在高级设置中，或作为单独操作提供。
- 用户启动尚未授权的节点后，页面显示授权链接。用户完成网页授权，插件自动刷新连接结果，并显示该节点的 Tailscale IP。
- 用户填写要通告的网段后，可以预览插件建议修改的 OpenWrt 网络接口和防火墙规则。点击“应用网络配置”后，插件才写入改动。以 `192.168.1.0/24` 为例，新规则仅允许来自 Tailscale 的流量转发到该网段，路由器自身的 LuCI 和 SSH 管理访问沿用原有规则。
- 日志页分别展示自动刷新的运行日志和安装与更新记录。即使首次下载失败、服务尚未启动，用户也能在安装记录中看到失败原因。
